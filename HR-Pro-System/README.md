# HR Pro System - نظام إدارة الموارد البشرية الاحترافي

## نظرة عامة
نظام متكامل لإدارة الموارد البشرية مبني بتقنيات الويب الحديثة (HTML, CSS, JavaScript) مع تخزين محلي للبيانات.

## المميزات الرئيسية

### 🔐 الأمان والصلاحيات
- تسجيل دخول آمن بتشفير SHA-256
- نظام صلاحيات متعدد المستويات (مدير، مدير قسم، موارد بشرية، موظف)
- إدارة الجلسات مع خيار "تذكرني"
- تسجيل جميع الأنشطة

### 📊 لوحة التحكم
- مؤشرات أداء رئيسية (KPIs) حية
- رسوم بيانية تفاعلية (Chart.js)
- نشاط حديث للمستخدمين
- تصدير البيانات

### 👥 إدارة الموظفين
- ملفات شخصية شاملة
- بحث وفلترة متقدمة
- عرض شبكي وقائمي
- إضافة/تعديل/حذف
- تصدير إلى Excel/CSV

### ✅ نظام المهام (Kanban)
- سحب وإفلات بين الحالات
- أولويات متعددة (عاجلة، عالية، متوسطة، منخفضة)
- تواريخ استحقاق مع تنبيهات
- تعيين للموظفين

### 🔄 الانتقالات
- طلبات نقل بين الأقسام
- سير عمل الموافقة
- تتبع الحالة
- ملاحظات للموافقين

### 📦 العهد والأصول
- تتبع الأجهزة والمعدات
- أرقام تسلسلية
- تواريخ الضمان مع تنبيهات
- تخصيص وإرجاع

### 💰 السلف والتحصيلات
- أنواع متعددة (سلف، دفعات مقدمة)
- نظام أقساط
- متابعة السداد
- موافقات إلكترونية

### 📄 التقارير
- تقارير شاملة لكل وحدة
- تصدير PDF و Excel
- طباعة بتنسيق احترافي
- إحصائيات وتحليلات

### 🔔 الإشعارات
- إشعارات فورية في التطبيق
- إشعارات المتصفح
- أصوات تنبيه
- مركز إشعارات شامل

### ⚙️ الإعدادات
- تخصيص السمة (فاتح/داكن/أزرق)
- حجم الخط
- إعدادات الإشعارات
- نسخ احتياطي واستعادة
- تصدير/استيراد الإعدادات

### 🌐 تعدد اللغات
- العربية (افتراضي)
- الإنجليزية
- دعم RTL/LTR

### ⌨️ اختصارات لوحة المفاتيح
- Ctrl+K: بحث شامل
- Escape: إغلاق النوافذ

## التثبيت والاستخدام

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Edge, Safari)
- اتصال بالإنترنت (لـ Chart.js و Font Awesome من CDN)

### التشغيل
1. افتح ملف `index.html` في المتصفح
2. سجل الدخول باستخدام:
   - اسم المستخدم: `admin`
   - كلمة المرور: `123456`

### بيانات التجربة الإضافية
| المستخدم | كلمة المرور | الصلاحية |
|---------|------------|----------|
| admin | 123456 | مدير النظام |
| manager | 123456 | مدير قسم |
| employee | 123456 | موظف |

## التقنيات المستخدمة

- **HTML5**: هيكل الصفحة
- **CSS3**: التنسيقات والتصميم
- **JavaScript (ES6+)**: المنطق والوظائف
- **Chart.js**: الرسوم البيانية
- **Font Awesome**: الأيقونات
- **LocalStorage**: تخزين البيانات

## التخزين

يستخدم النظام `localStorage` لحفظ البيانات محلياً:
- `hrpro_users`: بيانات المستخدمين
- `hrpro_employees`: بيانات الموظفين
- `hrpro_tasks`: المهام
- `hrpro_transfers`: طلبات النقل
- `hrpro_custodies`: العهد والأصول
- `hrpro_finances`: السلف والتحصيلات
- `hrpro_activities`: سجل النشاطات
- `hrpro_notifications`: الإشعارات
- `hrpro_settings`: الإعدادات
- `hrpro_session`: جلسة المستخدم الحالية

## النسخ الاحتياطي

من قائمة الإعدادات يمكنك:
- **نسخ احتياطي**: تحميل كل البيانات في ملف JSON
- **استعادة**: رفع ملف نسخ احتياطي سابق
- **تصدير الإعدادات**: حفظ الإعدادات فقط
- **مسح البيانات**: حذف جميع البيانات (بحذر!)
