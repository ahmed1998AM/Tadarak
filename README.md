# نظام إدارة الموارد البشرية المتكامل | HR Pro System

نظام ويب متكامل لإدارة شؤون الموظفين والمهام المالية والإدارية، مبني بتقنيات الويب الحديثة (HTML/CSS/JS) مع تخزين محلي للبيانات ودعم كامل للعمل دون اتصال (PWA).

## ✨ الميزات الرئيسية

### 🔐 نظام الأمان والصلاحيات
- **واجهة تسجيل دخول احترافية** مع تشفير كلمات المرور (SHA-256)
- **نظام صلاحيات متقدم**:
  - المدير: وصول كامل لجميع الوحدات
  - الموظف: وصول محدود للمهام والبيانات الشخصية
- **حظر/إلغاء حظر الموظفين** من قبل المدير
- **تغيير كلمة المرور** من قبل أي مستخدم

### 📊 لوحة التحكم (Dashboard)
- إحصائيات حية ومباشرة
- عدد الموظفين النشطين
- المهام الجارية والمنجزة
- السلف النشطة
- رسم بياني تفاعلي لتوزيع الموظفين حسب الأقسام
- رسم بياني للمهام الشهرية
- سجل النشاط الأخير

### 👥 إدارة الموظفين
- إضافة/تعديل/حذف الموظفين
- تحديد الصلاحيات (مدير/موظف)
- تعيين الأقسام وكلمات المرور
- حظر موظف معين أو إلغاء الحظر
- بحث وفرز في قائمة الموظفين
- تصدير بيانات الموظفين إلى CSV/JSON

### ✅ نظام المهام المتقدم (Kanban Board)
- **لوحة سحب وإفلات** للمهام بين الحالات
- أربع حالات: للتنفيذ، قيد التنفيذ، مراجعة، مكتمل
- إمكانية تكليف الموظفين بالمهام (للمدير)
- الموظفون يرون مهامهم فقط ويمكنهم إضافة مهام جديدة
- فلترة تلقائية حسب الحالة
- تحديد تاريخ التسليم والأولوية والوصف

### 🔄 الانتقالات بين الأقسام
- طلب نقل موظف من قسم لآخر
- متابعة حالة الطلب (قيد الانتظار، موافق عليه، مرفوض)
- إشعارات تلقائية للمدير والموظف

### 📦 العهد والأصول
- تتبع الأصول المعهدة للموظفين
- أنواع متعددة للأصول (كمبيوتر، هاتف، تابلت، إلخ)
- حالة الأصل وتاريخ الإسناد والإرجاع
- تنبيهات للأصول القريبة من الإرجاع

### 💰 السلف والتحصيلات
- طلب سلفة جديدة
- تسجيل تحصيلات
- سجل مالي مفصل لكل موظف
- حالة السلفة (قيد الانتظار، مقبولة، مرفوضة، تم السداد)
- المدير يرى كل العمليات، الموظف يرى عملياته فقط
- ملخص مالي شامل

### 📊 التقارير
- تقرير الموظفين الشامل
- تقرير المهام والإنجازات
- تقرير المالية والسلف
- تصدير التقارير إلى CSV/JSON

### ⚙️ الإعدادات
- تخصيص اسم الشركة وساعات العمل
- اختيار اللغة (عربية/إنجليزية)
- اختيار الثيم (فاتح، داكن، أزرق، أخضر، بنفسجي، برتقالي، أحمر)
- تغيير كلمة المرور الشخصية
- النسخ الاحتياطي والاستعادة
- مسح البيانات (للمدير فقط)

### 🔔 نظام الإشعارات
- إشعارات داخلية فورية
- إشعارات للمهام الجديدة
- إشعارات لطلبات النقل
- إشعارات للسلف والتحصيلات
- تحديد الكل كمقروء

### 🎨 نظام الثيمات الاحترافي
- **7 ثيمات متاحة**:
  - فاتح (Light) - افتراضي
  - داكن (Dark Mode)
  - أزرق (Blue)
  - أخضر (Green)
  - بنفسجي (Purple)
  - برتقالي (Orange)
  - أحمر (Red)
- تغيير فوري للثيم مع حفظ التفضيلات
- انتقالات سلسة بين الألوان
- دعم الوضع الداكن التلقائي من النظام

### 🌐 الترجمة واللغات
- دعم كامل للعربية والإنجليزية
- تغيير اتجاه الصفحة تلقائياً (RTL/LTR)
- حفظ اللغة المفضلة في التخزين المحلي

### 📱 التصميم المتجاوب
- يعمل على جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب)
- قائمة جانبية قابلة للطي على الهواتف
- واجهة مستخدم عصرية وسهلة الاستخدام
- أيقونات Font Awesome احترافية
- دعم وضع الطباعة

### 📲 تطبيق ويب تقدمي (PWA)
- تثبيت كتطبيق على الهاتف أو الحاسوب
- العمل دون اتصال بالإنترنت
- تحديث تلقائي عند توفر إصدار جديد
- إشعارات دفع (Push Notifications)

## 🚀 التثبيت والاستخدام

### النشر على GitHub Pages

1. **أنشئ مستودع جديد** على GitHub
2. **ارفع الملفات** (`index.html`, `README.md`, مجلدات js, css, assets)
3. **فعّل GitHub Pages**:
   - اذهب إلى Settings > Pages
   - اختر الفرع `main` والمجلد `/ (root)`
   - احفظ التغييرات
4. **الموقع سيكون متاحاً** على: `https://username.github.io/repo-name`

### التشغيل المحلي

1. افتح ملف `index.html` في أي متصفح حديث
2. لا حاجة لأي خادم أو تثبيت إضافي

## 💾 التخزين

يستخدم النظام `localStorage` لتخزين البيانات محلياً في المتصفح:
- `hr_users`: بيانات المستخدمين
- `hr_employees`: بيانات الموظفين
- `hr_tasks`: المهام
- `hr_transfers`: طلبات الانتقال
- `hr_custodies`: العهد والأصول
- `hr_finances`: السلف والتحصيلات
- `hr_notifications`: الإشعارات
- `hr_theme`: الثيم المفضل
- `hr_lang`: اللغة المفضلة
- `hr_company_name`: اسم الشركة
- `hr_working_hours`: ساعات العمل
- `hr_animations`: تفعيل الرسوم المتحركة

## 🔒 الأمان

- كلمات المرور مشفرة باستخدام SHA-256 قبل التخزين
- الجلسات تُخزن في `sessionStorage` وتنتهي عند إغلاق المتصفح
- نظام حظر يمنع المستخدمين المحظورين من الدخول
- حماية من ثغرات XSS عبر تنظيف المدخلات

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكل الصفحة
- **CSS3**: التنسيق والتصميم المتجاوب
- **JavaScript (ES6+)**: المنطق والتفاعل
- **Chart.js**: الرسوم البيانية
- **Font Awesome 6**: الأيقونات
- **Google Fonts**: خطوط Tajawal
- **Service Worker API**: للعمل دون اتصال
- **Cache API**: لتخزين المؤقت
- **Notification API**: للإشعارات

## 📝 ملاحظات هامة

1. **البيانات محلية**: جميع البيانات تُخزن في متصفحك فقط. مسح بيانات المتصفح سيحذف كل البيانات.
2. **لا يوجد خادم**: النظام يعمل بالكامل على جانب العميل (Client-side).
3. **متوافق مع المتصفحات**: يعمل على Chrome, Firefox, Safari, Edge.
4. **النسخ الاحتياطي**: يُنصح بأخذ نسخ احتياطية دورية من خلال ميزة تصدير البيانات.
