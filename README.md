# نظام إدارة الموارد البشرية المتكامل | HR Pro System

نظام ويب متكامل لإدارة شؤون الموظفين والمهام المالية والإدارية، مبني بتقنيات الويب الحديثة (HTML/CSS/JS) مع تخزين محلي للبيانات.

## ✨ الميزات الرئيسية

### 🔐 نظام الأمان والصلاحيات
- **واجهة تسجيل دخول احترافية** مع تشفير كلمات المرور (SHA-256)
- **
- **نظام صلاحيات متقدم**: 
  - المدير: وصول كامل لجميع الوحدات
  - الموظف: وصول محدود للمهام والبيانات الشخصية
- **حظر/إلغاء حظر الموظفين** من قبل المدير
- **تغيير كلمة المرور** من قبل أي مستخدم

### 📊 لوحة التحكم (Dashboard)
- إحصائيات حية ومباشرة
- عدد الموظفين النشطين
- المهام الجارية والمنجزة
- السلف النشطة
- رسم بياني تفاعلي لتوزيع المهام (للمدير فقط)

### 👥 إدارة الموظفين
- إضافة/تعديل/حذف الموظفين
- تحديد الصلاحيات (مدير/موظف)
- تعيين الأقسام وكلمات المرور
- حظر موظف معين أو إلغاء الحظر
- بحث وفرز في قائمة الموظفين

### ✅ نظام المهام المتقدم (Kanban Board)
- **لوحة سحب وإفلات** للمهام بين الحالات
- ثلاث حالات: قيد الانتظار، جاري التنفيذ، منجزة
- إمكانية تكليف الموظفين بالمهام (للمدير)
- الموظفون يرون مهامهم فقط ويمكنهم إضافة مهام جديدة
- فلترة تلقائية حسب الحالة
- تحديد تاريخ التسليم والوصف

### 💰 السلف والتحصيلات
- طلب سلفة جديدة
- تسجيل تحصيلات
- سجل مالي مفصل لكل موظف
- حالة السلفة (قيد الانتظار، مقبولة، مرفوضة، تم السداد)
- المدير يرى كل العمليات، الموظف يرى عملياته فقط

### ⚙️ الإعدادات
- تخصيص اسم الشركة
- اختيار اللغة (عربية/إنجليزية)
- اختيار الثيم (فاتح، داكن، أزرق)
- تغيير كلمة المرور الشخصية
- تصفير النظام (للمدير فقط)

### 🎨 نظام الثيمات الاحترافي
- **3 ثيمات متاحة**:
  - أخضر فاتح (افتراضي)
  - داكن (Dark Mode)
  - أزرق
- تغيير فوري للثيم مع حفظ التفضيلات
- انتقالات سلسة بين الألوان

### 🌐 الترجمة واللغات
- دعم كامل للعربية والإنجليزية
- تغيير اتجاه الصفحة تلقائياً (RTL/LTR)
- حفظ اللغة المفضلة في التخزين المحلي

### 📱 التصميم المتجاوب
- يعمل على جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب)
- قائمة جانبية قابلة للطي على الهواتف
- واجهة مستخدم عصرية وسهلة الاستخدام
- أيقونات Font Awesome احترافية

## 🚀 التثبيت والاستخدام

### النشر على GitHub Pages

1. **أنشئ مستودع جديد** على GitHub
2. **ارفع الملفات** (`index.html`, `README.md`)
3. **فعّل GitHub Pages**:
   - اذهب إلى Settings > Pages
   - اختر الفرع `main` والمجلد `/ (root)`
   - احفظ التغييرات
4. **الموقع سيكون متاحاً** على: `https://username.github.io/repo-name`

### التشغيل المحلي

1. افتح ملف `index.html` في أي متصفح حديث
2. لا حاجة لأي خادم أو تثبيت إضافي

## 💾 التخزين

يستخدم النظام `localStorage` لتخزين البيانات محلياً في المتصفح:
- `hr_users`: بيانات المستخدمين
- `hr_tasks`: المهام
- `hr_finances`: السلف والتحصيلات
- `hr_theme`: الثيم المفضل
- `hr_lang`: اللغة المفضلة
- `hr_company`: اسم الشركة

## 🔒 الأمان

- كلمات المرور مشفرة باستخدام SHA-256 قبل التخزين
- الجلسات تُخزن في `sessionStorage` وتنتهي عند إغلاق المتصفح
- نظام حظر يمنع المستخدمين المحظورين من الدخول

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكل الصفحة
- **CSS3**: التنسيق والتصميم المتجاوب
- **JavaScript (ES6+)**: المنطق والتفاعل
- **Chart.js**: الرسوم البيانية
- **Font Awesome 6**: الأيقونات
- **Google Fonts**: خطوط Tajawal و Cairo

## 📝 ملاحظات هامة

1. **البيانات محلية**: جميع البيانات تُخزن في متصفحك فقط. مسح بيانات المتصفح سيحذف كل البيانات.
2. **لا يوجد خادم**: النظام يعمل بالكامل على جانب العميل (Client-side).
3. **متوافق مع المتصفحات**: يعمل على Chrome, Firefox, Safari, Edge.
4. **النسخ الاحتياطي**: يُنصح بأخذ نسخ احتياطية دورية من بيانات `localStorage`.
